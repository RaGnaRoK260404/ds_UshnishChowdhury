\# Web3 Trading Team - Data Science Assignment



\*\*Candidate:\*\* Ushnish Chowdhury



\## Project Overview



This project analyzes the relationship between trader behavior and market sentiment, using two datasets:

1\.  `historical\_data.csv`: A log of 180,000+ trades.

2\.  `fear\_greed\_index.csv`: A daily record of the market's Fear \& Greed classification.



\## Contents



\* `notebook\_1.ipynb`: Contains all Python code for data cleaning, merging, and analysis.

\* `ds\_report.pdf`: A full report summarizing the key findings and strategic insights.

\* `outputs/`: Contains all charts generated during the analysis.

\* `csv\_files/`: Contains the raw data used for the project (not included in this repo per instructions, but this is where it was stored locally).
